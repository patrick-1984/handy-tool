# 03 — Make five choices

**Platform:** Windows x64  
**Needs hardware:** no  
**Time:** about 10 minutes

Set exactly these five controls, then leave the rest alone. The goal is a predictable daily setup, not a tour of every option.

1. Choose the microphone you actually use at `General › Sound › Microphone`. Speak near it and keep the system default only when the correct device is already selected.
2. Open `Models`, download **Parakeet V3**, and select its model card. Keep Moonshine V2 Tiny if fast English notes are all you need. See [Pick the engine that fits the machine](../features.md#pick-the-engine-that-fits-the-machine).
3. Set `General › Transcription › Append Trailing Space = On`: [The next dictation doesn't run into the last one](../features.md#the-next-dictation-doesnt-run-into-the-last-one).
4. Set `General › Sound › Audio Feedback = On`: [Hear when the microphone is hot](../features.md#hear-when-the-microphone-is-hot).
5. Try `General › Transcription › Transcription Mode = Live` for one take: it shows text while you talk. The shipped default is `Post-Recording`; go back to it if the moving text distracts you. The trade-off is catalogued under [Watch the text appear, or wait for the most accurate pass](../features.md#live-or-post-recording).

Two pages can appear later but are intentionally out of this stage: `Post Process` is revealed by `Advanced › Post-processing › Post Processing = On`, and `Debug` is revealed with `ctrl+shift+d`. Do not enable either yet.
