# About settings

Open `About`, in the sidebar right after What's new. The page identifies the build you are running and opens the folders it writes to. Its first group is **Updates**: the same controls as [General › Updates](general.md), shown here too because this is where people look for them.

Catalog: [It looks and behaves like a Windows app](../../features.md#it-looks-and-behaves-like-a-windows-app) and [Usable with the keyboard, and readable](../../features.md#usable-with-the-keyboard-and-readable).

## About

### Application Language

`About › Application Language`

Selects one of the shipped interface locales; each option shows its native and English name. **Default:** the operating-system locale.

Catalog: [Use it in your language](../../features.md#use-it-in-your-language).

### Version

`About › Version`

Shows the running application version. **Default:** `v1.0.0` for this release.

Catalog: [What runs today, and what is planned](../../features.md#what-runs-today-and-what-is-planned).

### Source Code

`About › Source Code`

`View on GitHub` opens the public source repository. **Default:** `https://github.com/patrick-1984/handy-tool`.

### App Data Directory

`About › App Data Directory`

Shows and opens the active app-data location. **Default:** `File › %APPDATA%\pr.handy` for a normal Windows installation.

Catalog: [Where your data lives on disk](../../features.md#where-your-data-lives-on-disk).

### Log Directory

`About › Log Directory`

Shows and opens the file-log directory. **Default:** the logs directory under the active app-data location.

Catalog: [The logs still exist when you finally need them](../../features.md#the-logs-still-exist-when-you-need-them).

## Acknowledgments

### Handy

`About › Acknowledgments › Handy`

Shows the upstream project acknowledgment. **Default:** read-only acknowledgment text.

### Whisper.cpp

`About › Acknowledgments › Whisper.cpp`

Shows the speech-engine acknowledgment. **Default:** read-only acknowledgment text.

### Speaker detection models

`About › Acknowledgments › Speaker detection models`

Credits the pyannote segmentation (MIT) and WeSpeaker ResNet34 (CC BY 4.0) models, in their sherpa-onnx ONNX versions, that `History › Recordings › Make note with speakers` downloads. **Default:** read-only acknowledgment text.
