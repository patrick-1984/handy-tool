# Current Audio settings

Open `Current Audio`.

### Open floating window

`Current Audio › Open floating window`

Opens the separate live-transcript window. **Default:** closed.

Catalog: [Watch the words arrive in a window you can park anywhere](../../features.md#watch-the-words-arrive-in-a-window-you-can-park-anywhere).

### Copy

`Current Audio › Copy`

Copies the transcript currently shown; the label briefly becomes `Copied`. **Default:** no transcript is available on a fresh launch.

Catalog: [The transcript panel doesn't go blank between takes](../../features.md#the-transcript-panel-doesnt-go-blank-between-takes).
