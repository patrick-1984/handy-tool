# Keyboard Typer

## The moment

The remote console ignores paste, and a password prompt is the last place you want clipboard history involved. You prepare the text in Handy Tool, move focus to the target during the countdown, and let it arrive as simulated keystrokes.

## How it fits your day

Use Keyboard Typer for locked-down consoles, virtual machines, and prompts that reject clipboard input. Before you put a credential in it, read [The text never touches your disk](../features.md#the-text-never-touches-your-disk).

## Set it up

1. Enter the temporary text at `Keyboard Typer › Enter the text to type...`.
2. Leave enough time to reach the destination at `Keyboard Typer › Start delay`.
3. Keep character delivery conservative for the target at `Keyboard Typer › Key delay`.
4. Bind the action at `Keyboard Typer › Type Text Shortcut = ctrl+alt+t`.
5. Start from `Keyboard Typer › Go`, switch to a harmless target during the countdown, and verify the complete text before using the same timing in a console or password prompt.
